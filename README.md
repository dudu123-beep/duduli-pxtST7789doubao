# pxt-st7789-gmt024

ST7789 TFT LCD MakeCode 扩展，适用于 **金逸晨 GMT024-8p10p-SPI** (2.4寸 240×320) 等 ST7789 驱动屏幕。

## 接线方式

| 屏幕引脚 | micro:bit 引脚 | 功能 |
|---------|---------------|------|
| GND | GND | 地 |
| VCC | **3.3V** | 电源（⚠️ 不要接 5V） |
| SCL | pin13 | SPI 时钟 |
| SDA | pin15 | SPI 数据 |
| RES | pin2 | 复位 |
| AO | pin1 | 数据/命令 (DC) |
| CS | pin0 | 片选 |
| BL | pin8 | **背光使能** |

## 使用方式

在 MakeCode 编辑器中：

1. 打开 [makecode.microbit.org](https://makecode.microbit.org)
2. 新建项目
3. 点击齿轮图标 → **扩展**
4. 搜索并导入：`https://github.com/你的用户名/pxt-st7789-gmt024`

## 积木块说明

### 设置
- **初始化 ST7789 屏幕** — 设置引脚和分辨率
- **初始化 ST7789 (默认引脚)** — 快速初始化，使用 CS=P0, DC=P1, RST=P2, BL=P8, 240×320
- **设置旋转角度** — 0/1/2/3 对应 0°/90°/180°/270°
- **背光** — 开启或关闭背光

### 绘图
- **清屏颜色** — 用指定颜色填充整个屏幕
- **画点** — 在指定坐标画一个像素
- **填充矩形** — 画实心矩形
- **矩形框** — 画空心矩形
- **水平线 / 垂直线** — 画直线
- **直线** — 任意两点间画线（Bresenham 算法）
- **圆** — 可选项：填充
- **三角形** — 可选项：填充

### 文字
- **显示文字** — 显示字符串，支持大小写、数字、符号
- **显示数字** — 显示数值
- **居中文字** — 水平居中显示

### 高级
- **反色显示** — 开启/关闭反色
- **屏幕睡眠 / 唤醒**
- **屏幕宽度 / 屏幕高度** — 获取当前分辨率

## 示例

```blocks
st7789.initDefault()
st7789.fill(0x000000)
st7789.text(10, 10, "Hello World!", 0xFFFFFF, 0x000000, 2)
st7789.fillRect(50, 50, 100, 100, 0xFF0000)
```
